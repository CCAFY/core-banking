# 용어사전

도메인 용어와 뜻. **코드 표기는 팀이 정해서 채운다.**
테이블, 컬럼, 변수 이름은 이 표의 표기를 조합해서 만들고,
새 용어가 필요하면 코드보다 이 표를 먼저 고친다.

| 용어 | 코드 표기 | 뜻 |
|---|---|---|
| 원장 | | 계좌별 잔액과 거래를 기록하는 장부 전체 |
| 계좌번호 | | 계좌를 구분하는 번호 |
| 예금주 | | 계좌 주인 |
| 잔액 | | 계좌의 현재 금액 |
| 거래 | | 입금, 출금, 이체, 취소 같은 요청 한 건 |
| 추적번호 | | 요청을 구분하는 고유 값. 같은 요청이 두 번 와도 한 번만 반영하게 하는 데 쓴다 |
| 멱등성 | | 같은 요청을 여러 번 보내도 결과가 한 번 보낸 것과 같은 성질 |
| 복식부기 | | 모든 거래를 차변과 대변 양쪽에 같은 금액으로 적는 기록 방식 |
| 분개 | | 거래 한 건을 차변과 대변으로 나눠 적은 것 |
| 차변 / 대변 | | 복식부기의 왼쪽 / 오른쪽. 자산은 차변에서 늘고, 부채는 대변에서 는다 |
| 계정과목 | | 분개가 속하는 회계 계정. 예: 현금(자산), 보통예금(부채) |
| 거래 후 잔액 | | 그 거래가 반영된 직후의 계좌 잔액 |
| 영업일 | | 거래의 기준일자. 시스템 날짜와 다를 수 있다 |
| 일마감 | | 하루 거래를 닫고 영업일을 다음 날로 넘기는 작업 |
| 대사 | | 서로 다른 두 기록이 맞는지 맞춰 보는 작업 |
| 취소, 역분개 | | 원거래를 지우지 않고 반대 방향 분개를 새로 넣어 되돌리는 것 |

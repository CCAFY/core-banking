## 겹칠 때 정하는 규칙

- 1지망이 겹치면 하루 시간을 더 많이 쓸 수 있는 사람이 동시성과 이체를 맡는다. 두 영역은 난이도가 높고 다른 영역이 이 결과에 의존하기 때문이다.
- 시간도 같으면 2지망을 기준으로 다시 조정한다.

## 최종 결정 (합의 후 작성)

아직 2명이 답하지 않아서 아래는 **잠정안**이다. 지금까지 1지망은 겹치지 않았다.

| 영역 | 담당 | 상태 |
|---|---|---|
| 동시성 | 김상해 | 1지망, 겹치는 사람 없음 |
| 출금 | (미정) | Hoon 2지망. 남은 2명이 고르지 않으면 Hoon |
| 이체 | 강현 | 1지망, 겹치는 사람 없음. 하루 3시간 이상이라 규칙에도 맞음 |
| 멱등성 | (미정) | 김상해·강현 2지망. 남은 2명 답장 후 결정 |
| 취소 | Hoon | 1지망, 겹치는 사람 없음 |
| 영업일·대사 (3단계) | 김상해, Hoon, 강현 | 3명 모두 의향 있음. 3단계 시작 전에 나눈다 |

### 영역 사이 의존 관계

- 출금과 이체는 동시성에서 정한 Lock 방식을 그대로 쓴다. 동시성은 2단계 초반에 먼저 끝내야 한다.
- 취소의 "동시 취소에도 이중 취소 없음"은 동시성(Lock 방식)과 멱등성(중복 방지)에 모두 걸린다. 두 담당자와 경계를 미리 맞춘다.
- 이체의 "반대 방향 이체 동시 처리"는 데드락 문제다. 출금이 동작하기 전에는 재현 테스트부터 만든다.
